## 详细行程

### 10月1日 南京---兰州

| 项目 | 内容 |
| --- | --- |
| 路线 | 南京 → 兰州<br>7:00起床，睡觉/刷剧/玩玩具/串车厢活动筋骨（经过哪些地点提前查给孩子讲）<br>10:30 地铁去高铁站（玩具放在单独的包里）<br>21:08 下车，酒店休息，适应海拔 |
| 早餐 | 高铁餐or面包, 泡面, 火腿, 瓜子, 上火车前购买一箱水 |
| 午餐 | 高铁餐or面包 |
| 晚餐 | 兰州西站（嘉峪关烧烤（炒拨拉））、碳元素纯木炭烧烤（元店）<br>兰州牛肉面（磨沟沿总店/吾穆勒）<br>手抓羊肉（白建强/小西湖）<br>其他：放哈甜胚子奶茶、酸奶、黑豆皮、炒拨拉、烤羊肉、烧烤 |
| 住宿 | 下车后坐地铁， 兰州全季酒店省政府店 |
| 费用 | 大交通、餐饮、住宿 |
| 备注 | 落地后需购买物资：方便面、矿泉水、巧克力、葡萄糖、其他零食、饮料|
| 穿衣风格建议 | 总体建议：带冲锋衣+打底裤（女生方便穿裙子）；带白裙子和亮色纱巾、牛仔系列 |

### 10月3日 张掖---七彩丹霞---嘉峪关---敦煌夜市

| 项目 | 内容 |
| --- | --- |
| 路线 | 张掖 （30km，1h） → 七彩丹霞 （227km，3h） → 嘉峪关 （374km，4h） → 敦煌夜市 |
| 早餐 | 张掖 |
| 午餐 | 嘉峪关滚记糊锅总店、小李麻辣烫、嘉峪关烤肉王子烤肉 |
| 晚餐 | 敦煌塔高蛋面麻辣烫、沙洲夜市（泡儿油糕）、炒粉 |
| 住宿 | 敦煌 |
| 费用 | 餐饮、住宿<br>嘉峪关联票：110（不建议去，商业化严重）<br>鸣沙山月牙泉门票：110 |
| 备注 | 嘉峪关拍照地点：导航胡杨里/王维山，如果想去看建议逛关城看看就可以了<br>鸣沙山月牙泉建议：入园先骑骆驼，要在19:30之前到山顶，晚上有万人演唱会可以侧门进，离沙山近，不排队 |
| 穿衣风格建议 | 嘉峪关：民族风（艳色系）/白裙（配个纱巾）；鸣沙山：红裙子/牛仔系列/白裙子（配红纱巾） |

### 10月4日 敦煌---鸣沙山月牙泉---莫高窟---大柴旦

| 项目 | 内容 |
| --- | --- |
| 路线 | 敦煌 （5km，10min） → 鸣沙山月牙泉 （15km，0.5h） → 莫高窟 （38km，5.5h） → 大柴旦 |
| 早餐 | 敦煌 |
| 午餐 | 敦煌顺张驴肉黄面【备注：范记/马平烤羊肉】、胡羊焖饼（配沙葱炒蛋）<br>沙葱（4-5斤）、羊肉粉汤（杨老七）<br>驴肉黄面、杏皮水（刘红杏杏皮水） |
| 晚餐 | 敦煌阿克塞：清真·萨萨特色大盘鸡 |
| 住宿 | 阿克塞 |
