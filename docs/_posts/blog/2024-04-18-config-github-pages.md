本文描述搭建博客的初衷和选择.  

## 背景

我想搭建自己的博客, 趁着自己还对代码有那么一点点热情, 输出一些体会和总结.  

同时我不想在搭建博客上浪费太多时间, 而想把精力集中到写博客本身.  

经过一番探索, 我找到了 GitHub Pages, 感觉符合我的预期:  

 - 托管在 GitHub, 不需要个人维护, 也没有到期和续费的问题 (即使有一天人不在了, 页面也会在吧)  
 - 内置 Jekyll, 推送 Markdown 即可, 无需本地构建和手动部署  

## GitHub Pages 基础认知

### 站点类型

一类是个人或组织站点, 资源存储在仓库 `username.github.io`, 访问 URL 为 `username.github.io`  
另一类是项目站点, 资源存储在项目仓库, 可以是仓库的根目录或者 `/docs` 目录, 访问 URL 为 `username.github.io/project_name`
