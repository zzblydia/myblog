# 笔记本电脑安装使用 Ubuntu 22.04

## 背景
1. 朋友淘汰了一台 2018 款的 `联想拯救者` 笔记本电脑送给我, 这台电脑以前的 Windows 系统就是我安装的.  

    这台电脑有点邪门, 当时装系统费了很大劲, 最后曲线救国：先装非官方 Windows, 再用 ISO 升级到官方版才成功.  

    配置如下:  
    ```
    CPU: i7 8750H 12核
    内存: 16G
    硬盘: 256 SSD（坏道）
    集成： UHD Graphics 630
    独立显卡: NVIDIA GeForce GTX 1060
    ```

2. 我驱车来回 60 公里拿了回来, 想着物理机安装 FnOS, 加上我两个 USB 硬盘组 NAS, 以便替代迷你主机中的虚拟机 FnOS（虚拟主系统 + 直接使用物理磁盘）.  

3. 我自己的笔记本电脑是 2017 年的华硕 U4000UQ, 屏幕只有 13.6 寸. 所以我一直想买一个显示器当副屏.  

    可是每次打开购物网站, 商品琳琅满目、评测七嘴八舌, 就感觉难以下手, 没有看到过无脑入的产品.  

    因为穷, 潜意识里就会总想着能买到性价比高的. 同时, 商品的丰富增加了购物难度和购物成本（时间）.

### 2026-05-24 初始系统安装
从早上 5:30 一直装到 8:00, 直到换了三个版本才成功.

| 版本            | 结果   | 原因                                          |
| --------------- | ------ | --------------------------------------------- |
| Ubuntu 26.04    | 失败   | 安装中遇到 problem, 卡在安装界面到不了最后     |
| Ubuntu 24.04.4  | 失败   | 安装中遇到 problem, 卡在安装界面到不了最后     |
| Ubuntu 22.04.5  | 成功   | 安装成功, 重启后遇到 problem, 忽略继续使用     |
| Debian 13.6     | 未尝试 | 问 AI 说系统太新不建议安装                     |

结论: 果然电脑有古怪 + 老电脑不宜装新系统.
