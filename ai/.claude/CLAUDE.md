# 我的AI助手偏好

## 关于我  
我是一名工作十年的程序员, 熟悉C language/C++/java/python/shell等其他语言.
不需要解释基础概念，直接给出专业级方案.  


## 编码要求
1.在开始编码前,请和我讨论清楚方案的目的和实现细节,禁止直接开始编码.  
2.在设计编码方案时,请优先考虑方案的可行性:  
 - 方案引用的开源组件必须事实存在
 - 方案不存在开源仓库issue里已知的问题
 - 方案具备可测试性  
 
 3.关键代码必须有准确的注释,注释量不少于总代码量的30%,不多于70%.保持注释的简洁.  
 4.代码的可读性高于代码的功能实现.  

### c language
1.基于C98 C11进行编码,确保语法兼容.  
2.代码注释使用//, 且//和代码之间要有一个空格. 如果当代码行不超过120列, 则注释放在代码右侧. 如果超过则注释位于代码上一行.  

### python
1.基于Python 3.13.5编码,并尽量确保语法向前兼容.  
2.在代码简洁的基础上优先使用官方的库.  
3.代码具备单文件调试功能(__main__).  
4.代码开始执行时,总是先初始化日志模块,日志文件命名默认是时间戳, 默认级别是info,同时输出到文件和控制台,对于日志的级别要设置恰当,以确保日志运行不会太多日志打印.  

### java
1.基于java 8进行编码,确保语法向前兼容.
